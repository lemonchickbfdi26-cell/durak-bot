# Дурак Бот

Android-приложение, которое само играет в «Дурак Онлайн» (переводной, 36 карт, 1 на 1) **за столом против ботов игры**: смотрит на экран, узнаёт карты и перетаскивает их.

## Скачать

👉 [durak-bot.apk](https://github.com/lemonchickbfdi26-cell/durak-bot/releases/download/latest/durak-bot.apk)

## Как пользоваться

1. Установи APK.
2. «1. Включить бота» → «Дурак Бот» в Спец. возможностях → включить.
3. «2. Разрешить боту видеть экран» → «Начать».
4. Открой «Дурак Онлайн», сядь за стол с ботом. Сверху появится панель.
5. Жми ▶ — бот сам нажмёт «Готов» и будет ходить.

Играй ботом только против ботов игры, не против живых людей.

## Как устроено

- `DurakVision` — находит значки карт (достоинство + масть) в руке и на столе, козырь, кнопки и чей ход (по рамке аватарки)
- `Templates` — образцы значков, вырезанные из скриншотов игры
- `Durak` — стратегия: атака с младших, подкидывание, отбой самыми дешёвыми картами, перевод, «беру», память вышедших карт
- `BotService` — панель поверх игры и жесты
